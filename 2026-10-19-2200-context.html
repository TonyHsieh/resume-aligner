2
Interactive Interview Prep CLI (rf prep <job_id>):

Each aligned job already generates 3 targeted disambiguation questions in questions.md. Build an interactive interview prep command in rf that quizzes the user on role-specific technical trade-offs, anticipated architectural challenges, and STAR-method responses based on their verified fact ledger.

3
Automated ATS Keyword Density & Coverage Audit:

Implement an automated keyword density analyzer in validate.py that computes the exact lexical and semantic overlap between the ingested jd_raw.txt and the tailored resume.docx, scoring keyword frequency, missing domain terms, and ATS readability.

4
Automated LinkedIn Recruiter Search URL Launcher:

Add a CLI shortcut (e.g., ./rf outreach <job_id> --open) that copies the tailored 2-sentence note to the clipboard and opens the exact LinkedIn Boolean search query directly in the browser for instant one-click outreach.

5
Application Status Transition Hooks:

When marking a job as applied via ./rf jobs mark <job_id> applied, automatically timestamp the date, prompt for application portal confirmation, and sync the status back to the Google Sheet with an optional reminder for 7-day follow-up.
